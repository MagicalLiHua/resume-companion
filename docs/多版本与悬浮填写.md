# 多版本简历与自动悬浮填写

2026-09-11，已按用户要求纳入 0.4.0。

## 使用体验

资料页维护多个命名版本，可以新建空白版本、复制当前版本、重命名、切换和删除。每份包含独立的基本信息、经历、补充资料、来源与上一份。最多 30 份，同时服从本地总容量预算。

招聘网页右下角自动显示“简”按钮。点击展开窗口，选择本次要用的版本，自动扫描并展示可填内容；核对后点击“确认填写 ✓”。多段经历有歧义时选择对应条目，陌生字段可以请求模型建议。

填写版本与编辑版本分别选择。可以用版本 A 的已保存资料填写，同时保留编辑页里版本 B 的草稿；草稿始终不参与填写。版本修改或删除会使相关旧预览失效。完整备份包含全部版本，恢复时列出覆盖范围。

## 自动入口与权限

按用户明确授权，在普通 HTTP/HTTPS 网页加载顶层内容脚本，根据招聘域名、页面标题或简历字段线索显示入口；可在“备份与恢复”关闭。浏览器内部页面和默认子框架不注入。

悬浮球使用独立的样式容器，内容由受控扩展页面显示。背景进程为当前页面注册随机会话令牌；嵌入页面的请求需要匹配令牌和标签页。网页伪造 iframe 无法获取资料。页面填写仍经过扫描版本、来源、当前值、用户确认和回读检查。

自动显示是启发式检测，不等于所有网站或控件已经适配。页面限制悬浮窗口时可用工具栏侧边栏；真实网站按用户安排稍后试用。

## 对参考插件的观察

检查的是本机已有的求职方舟 2026.9.9 发布包，未执行其插件或调用原厂服务。

- manifest 通过全网页内容脚本加载 UI，页面结束加载时注入交互脚本。
- `resumeInterface.js` 创建 Shadow DOM 容器，并用页面“简历/姓名”等文本线索控制自动显示。
- 样式把约 50 像素按钮放在右下角，距底边和右边约 40 像素。
- 展开窗口含简历版本选择项、当前选中标记和填写入口。

本项目按这些交互线索实现自己的入口，并复用现有来源预览和填写代码。原插件业务 API 不属于本项目运行依赖。

## 验证

`tests/e2e/versions-widget.spec.ts` 验证版本之间的数据独立、全部版本备份恢复、自动悬浮入口、选择其他版本填写、未保存草稿隔离、网页无法直接读到资料及伪造 iframe 拒绝。具体结果见[本次验收报告](纯插件版实现与验收.md)。
