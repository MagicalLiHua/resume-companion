## 已知限制

- 第一次使用专用 Chrome 需要登录招聘网站；后续复用同一 Profile。第三方登录是否兼容取决于网站策略。
- 同一时间只允许一个任务操作专用 Chrome；其他任务保持连接，但必须等待自动接管或明确调用 `browser_takeover`。
- 自定义画布、封闭 Shadow DOM、跨域身份验证、强反自动化和只有视觉坐标的控件可能需要人工处理。
- 通用组件识别依赖标签、ARIA、章节和可见候选；重复字段无法唯一确认时停止，不按 DOM 顺序猜选。
- 兼容范围仅限上表实测版本与场景；不代表 Ant 全部版本、Element UI 2 或 Element Plus 的全部变体。Element 长列表使用普通 ElSelect，尚未验证 ElSelectV2。
- 日期时间、周、季度、仅年份、格式/精度不明，以及无法证明完整集合的折叠多选不在本批支持范围内；原生日期的非单位 step 也会明确停止。地址严格按调用者给出的页面路径选择，不自动补省/市层级。
- 尚未全面覆盖就地替换单列的级联、每个层级的故障注入、2500ms 延迟矩阵和全部范围面板联动变体；需要相应夹具或真实失败样本才能扩大承诺。
- 页面级 generation 不能把任意网站副作用变成浏览器事务；动作结果不确定时会返回分类并要求局部观察。
- 页面语义缓存由 Supervisor 持有，可跨任务 MCP 会话复用；Supervisor 版本升级或退出后首次调用需要重建 overview。
- macOS 已完成主要开发验证；Windows 和 Linux 的真实 Chrome 生命周期仍需更多机器覆盖。
- 合成回归证明协议与执行层可工作，不等同于真实网站性能结论。达到计划中的输出和快照降幅前，不宣称性能优化已经完成。

同平台企业兼容扫描进一步区分精确企业模板、可信平台兼容页面和非可信来源候选；按 DNS 标签边界验证 Moka、北森、大易、国聘来源，51job 保持企业模板门控。回归覆盖企业模块子集、未知可选内容继续填写、未知必填内容阻断，以及准备摘要中的页面/资料模块交集。这证明扫描和计划边界，不等于新增企业已经完成原站保存与刷新验收。

原站在专用浏览器使用虚拟资料，以下计时从结构化资料和已加载的页面开始，由 SDK 连续调用 prepare / start / resume；不含首次简历整理、登录、页面加载、独立验收脚本、保存或提交，也不等同完整模型会话的用户耗时。
