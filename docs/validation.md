# 验证与兼容范围

版本：Chrome 扩展 0.7.1 / MCP 插件 0.4.1 / 工具协议 2.0。定位：开发预览版。

## 已验证

2026-09-18，本地 macOS 环境完成：

- TypeScript 检查和生产构建。
- 19 项单元测试：协议双版本解析、资料原子写入、记录 ID、来源解析、修订冲突、并发写入、索引重建、桥接生命周期与标签页激活。
- 21 项浏览器回归：多页表单、重复经历、动态搜索、级联、年月、虚拟候选、React 受控输入、用户手改、旧引用、取消、保存失败和最终提交阻止。
- MCP 契约测试：无 Chrome 时管理资料、十工具目录、资料引用在 MCP 解析、浏览器线协议只接受字面值、取消传递。
- MCP→隔离 Chrome 集成测试：保存合成资料、连接扩展、观察、填写、验证、撤销，并确认浏览器存储不含姓名或邮箱。
- 旧 resume_state 保留测试：升级只迁移桥接开关，不删除旧资料。

虚构银行流程会连续填写基本资料、两条教育经历和一条实习，进入最终核对并断言最终申请提交次数为 0。

## 尚未承诺

- 真实招聘网站需要逐站试用；合成银行控件不等于整站验收。
- 目前只覆盖主文档，iframe 和 Shadow DOM 内控件未覆盖。
- DOM 合成事件无法满足所有网站对可信用户事件的要求。
- 页面回显不是招聘网站后台事务保证。未知结果需要重新观察或交给用户。
- 上传、验证码、密码、声明、删除和最终申请提交需要用户处理。
- Windows 与 Edge 尚未实际复测。

问题报告请使用合成资料和匿名控件结构，不要上传真实简历、账号、Cookie 或网页会话。
