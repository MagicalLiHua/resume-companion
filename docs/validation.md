# 验证与兼容范围

版本：Chrome 扩展 0.6.0 / MCP 插件 0.3.0 / 工具协议 1.0。定位：开发预览版。

## 已做的检查

2026-09-18，本地 macOS 环境完成：

- 类型检查与生产构建。
- 75 项单元测试、98 项浏览器测试，其中 18 项为 core 工具回归。
- MCP 的 core / legacy / all 列表和严格参数校验、取消传递。
- 真实 MCP→隔离 Chrome 扩展的通信、正式资料来源校验、填写、回读、撤销及重载。
- 多版本资料、备份、旧版迁移、悬浮入口和投递记录的既有回归。

测试器中的虚构银行覆盖完整四步流程：基本资料 → 两条教育经历 → 一条实习 → 最终核对。草稿与经历保存在本地夹具中，断言同时检查最终数据和零次最终申请提交。

动态控件覆盖已渲染候选、异步搜索、级联父子层更新、年月选择、虚拟列表滚动、React 状态、重复字段、用户手改、过期引用、保存失败与取消。故障用例验证可靠停止，不算作填写成功。

开发过程中也做过模型根据观察组合工具的试验。由于试验横跨开发构建、模型持有开发上下文，且部分原始轨迹未完整保留，公开发布不将其列为独立模型基准，不发布成功率或 token 节省宣传。仓库可复现的验证入口是自动化测试。

## 尚未承诺的支持

- 真实招聘网站的完整持久保存和跨步骤链路，需要逐站实际试用。银行控件开发参考和合成测试不等于整站验收。
- 当前只覆盖主文档，iframe 与 Shadow DOM 内控件未覆盖。
- DOM 合成事件无法满足所有网站对可信用户事件的要求。
- 保存成功以页面回显为依据，不是后台事务承诺。无法确认时应重新观察或交给用户。
- 上传、验证码、密码、声明确认、删除记录和最终申请提交需要用户处理。
- Windows / Edge 尚未实际复测；GitHub CI 的具体状态见对应工作流。

遇到问题，请提供匿名的控件结构、复现步骤、扩展版本及合成数据。不要上传真实简历、招聘网站账号或会话。
