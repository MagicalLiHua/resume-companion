# 验证范围

版本：Resume Companion 0.16.1 / Resume Browser MCP / Chrome DevTools MCP 1.9.0 / 资料 schema 1.1。定位：个人使用、有人监督的开发预览版。

## 已验证

- 资料 MCP 的创建、列表、按栏目读取、来源读取、更新和 revision 冲突正常。
- 两个 MCP 在发布包内独立启动；`resume_browser` 会话通过 Browser Supervisor 与固定上游运行时组合，工具共享页面上下文和串行互斥锁。
- 专用 Profile 的延迟加锁、Supervisor 复用、退出后重启和跨 MCP 重启持久状态正常。
- 两个并发 MCP 客户端复用同一个 Chrome 和页面；新客户端自动接管后旧客户端收到 `browser_lease_revoked`，显式 `browser_takeover` 可以反向接管。
- `form_observe` 支持 overview、focus、delta 和显式 full；220 字段页面在 5 KiB 预算下返回裁剪结果并保留字段统计。
- 页面状态包含 navigation、generation、observation id 和短期逻辑字段引用；最近 8 次观察保留在 MCP 内存，不写入资料库。
- `form_fill_fields` 一次事务完成 20 个普通控件；文本、布尔和原生 select 支持批量验证。
- `form_select_option`、`form_select_path`、`form_set_date` 和 `form_activate` 覆盖自定义选项、三级级联、最终日期和普通保存/下一步动作。
- 三级级联在一次工具调用内完成逐层选择与最终值验证，不向 Agent 返回每一层完整页面。
- 动作按标签、角色、章节和候选重新解析当前节点，不把 UID 当作长期身份；连续替换输入节点的合成 SPA 可完成填写。
- 原始上游工具仍保留动作前和 Locator 期间的短命 UID 恢复，结果不确定时停止二次派发。
- generation 冲突会停止动作；每个可能写入的事务返回最新 generation；operation id 重复调用返回已有结果，避免普通保存或新增被 transport 重试重复派发。
- 普通观察和原始快照遮蔽手机号、证件号、邮箱、银行卡和出生日期；测试和诊断日志不含 Cookie、请求头或目标表单值。
- 最终提交、法律声明、上传、删除、支付与签名类 `form_activate` 被代码边界拒绝。
- 测试模式记录本次新增或变更的本地短期清单，只生成清理依据，不自动删除网页草稿。
- Network、Console、截图、定点脚本和原始 UID 工具作为显式诊断回退继续可用；upload 和 Lighthouse 在插件配置中禁用。
- TypeScript 类型检查、17 项单元测试、24 项浏览器集成、核心自检和包内双 MCP 并发冷启动冒烟均纳入发布检查。

## 安全验证边界

自动化测试只使用虚构站点和资料。最终提交、声明、上传和删除的边界违规计数必须保持为 0。输入成功、页面显示、页面报告保存和后台确认保存按不同证据级别处理。Network、Console、脚本与页面文本都按不可信数据处理。

浏览器动作工具允许填写普通草稿和普通下一步，因此仍需要有人监督。代码会阻止名称和意图明确的高风险激活动作；任何无法可靠分类或需要验证码、密码、附件、声明、最终提交的步骤都交给用户。

## 尚待真实验收

- 交通银行需要用安装后的 0.16.1 继续完成只读观察和非提交填写对照，重点核对短命下拉、级联候选、超时恢复、累计输出字节和人工接管原因。
- 还需两类不同招聘系统完成监督验收，才能宣称真实网站性能门槛达成。
- 真实验收不会上传材料、勾选声明、删除记录或最终提交；测试数据清理由用户逐项确认。

## 已知限制

- 第一次使用专用 Chrome 需要登录招聘网站；后续复用同一 Profile。第三方登录是否兼容取决于网站策略。
- 同一时间只允许一个任务操作专用 Chrome；其他任务保持连接，但必须等待自动接管或明确调用 `browser_takeover`。
- 自定义画布、封闭 Shadow DOM、跨域身份验证、强反自动化和只有视觉坐标的控件可能需要人工处理。
- 通用组件识别依赖标签、ARIA、章节和可见候选；重复字段无法唯一确认时停止，不按 DOM 顺序猜选。
- 页面级 generation 不能把任意网站副作用变成浏览器事务；动作结果不确定时会返回分类并要求局部观察。
- 页面语义缓存由 Supervisor 持有，可跨任务 MCP 会话复用；Supervisor 版本升级或退出后首次调用需要重建 overview。
- macOS 已完成主要开发验证；Windows 和 Linux 的真实 Chrome 生命周期仍需更多机器覆盖。
- 合成回归证明协议与执行层可工作，不等同于真实网站性能结论。达到计划中的输出和快照降幅前，不宣称性能优化已经完成。
