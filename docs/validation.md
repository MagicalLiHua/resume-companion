# 验证与兼容范围

版本：MCP 插件 0.6.0 / 工具协议 2.1。定位：开发预览版。

## 已验证

2026-09-18，本地 macOS 环境完成：

- 根项目和 MCP 严格 TypeScript 检查、生产构建及单元测试。
- 资料原子写入、记录 ID、来源解析、修订冲突、并发更新和索引重建。
- 快照引用、敏感操作阻止、字段当前值校验、操作去重、条件撤销和 DevTools 运行模式。
- MCP 契约：十工具目录、资料引用仅在 MCP 解析、取消信号和结构化错误。
- 无扩展的真实集成：MCP 启动固定 Chrome DevTools MCP 运行时、打开隔离 Chrome、观察合成页面、从本地资料填写、回读验证并撤销。
- 虚构招聘表单中的批量输入、滚动、用户手改保护、最终提交阻止和条件撤销。

所有自动化测试使用合成资料。测试运行后会关闭隔离 Chrome 并删除临时 Profile。

## 当前承诺与限制

- 默认连接 Chrome 144+ 的当前 Profile，避免重复登录；用户需要先启用远程调试，并为每次新连接点击 Allow。
- 不需要也不会申请修改 macOS App 的权限。
- 真实招聘网站需要逐站试用；合成银行控件不等于整站验收。
- 无障碍树可以覆盖部分 iframe 与 Shadow DOM 控件，但并非所有自绘组件都可访问。
- 横向滚动目前交给用户；纵向滚动使用真实键盘事件。
- 页面回显不是招聘网站后台事务保证；未知保存结果必须重新观察。
- 上传、验证码、密码、声明、删除和最终申请提交由用户处理。
- Windows 和 Edge 尚未完成实际复测。

问题报告请使用合成资料和匿名控件结构，不要上传真实简历、账号、Cookie 或网页会话。
