# 当前交付：浏览器插件 + Codex 批量能力 0.5.0

更新：2026-09-11。浏览器插件仍可独立使用；Codex 插件通过本机 MCP 与 Chrome 扩展交换结构化表单数据，不用视觉识别即可处理一个或多个已经打开的网申标签页。

- 直接加载本项目的 `dist` 目录，或解压 `artifacts/resume-companion-0.5.0.zip` 后加载其中的 `extension`。
- Chrome 开启开发者模式，加载后可使用资料页、右下角悬浮窗口与独立投递记录页。
- 支持多份命名简历、Markdown 导入、补充资料、草稿恢复、完整备份、DeepSeek Anthropic / OpenAI 兼容模型匹配。
- 投递记录直接保留公司、岗位、网址和时间，支持搜索、编辑、导出及统计，无逐条确认流程。
- Codex 能力源码位于 `plugins/resume-companion`，提供单页兼容工具以及标签页枚举、批量扫描、填写、校验和撤销工具；没有提交、下一步、上传、验证码或同意授权工具。

浏览器独立操作见[安装与体验](安装与体验.md)，Codex 批量能力见[Codex 批量网申能力](Codex网申能力最小验证.md)，纯插件基线测试证据与实际限制见[纯插件版实现与验收](纯插件版实现与验收.md)。真实招聘网站仍按用户安排稍后试用。

历史网页与后端的启动和服务器记录保留在[历史交付说明](历史版本/当前交付与启动-0.3.2.md)。本次开发不部署或关闭这些服务。
