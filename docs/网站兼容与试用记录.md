## 当前通用支持范围

已经通过本地合成表单的普通文本、原生选择、单选、年月及明确技能复选项；具备经历绑定、拟填内容预览、默认保留已有值、回读与有条件撤销。自定义下拉、地区级联、iframe、Shadow DOM 和特殊证书控件先提示手填。

现有样本为 20 类、200 个标注字段，32 项浏览器回归通过。它们验证共同逻辑，不能代表上面三个真实站点的覆盖率。

## 登录后验收流程

1. 用户自行登录目标网站，进入可编辑简历页并展开需要检查的栏目。先确认网站是否自动保存。
2. 第一轮只扫描并核对字段来源、分组、重复经历与拟填值；记录跳过项及实际控件类型。
3. 将复杂控件结构转成不含个人资料的仿真用例，完成必要适配及回归。
4. 在用户确认可操作的真实草稿里，用用户已确认的资料执行填写和回读。自动保存的网站不能使用虚构简历做写入验收。
5. 每个代表流程做 3 轮，覆盖单段、多段经历与已有值/页面变化；保存、下一步和提交由用户决定。

首轮选 2 个实际可访问流程，优先国聘和智联；应届生可作为候补。选择两个是验收样本数，后续支持范围可继续增加。

## 自用与试用

当前网页维护版已可自用；先由项目所有者体验 3–5 天，再由其自行邀请 2–5 位同学试用约一周。真实观察尚未开始，不能通过自动化回归替代日历时间。

反馈只需提供插件版本、站点域名和页面类型、期望行为、实际表现、能否重现；不要提供 API Key、密码、完整简历或包含个人资料的整页 DOM。逐条记录后修复阻塞问题，再决定扩展站点范围。
