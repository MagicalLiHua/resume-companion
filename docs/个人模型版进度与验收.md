# 个人模型版进度与验收（0.4.0）

2026-09-11，后端与网页 0.4.0 已部署到 `10.160.108.2`，插件保持 0.3.2。入口为现有 SSH 通道下的 `http://127.0.0.1:18080`。详细使用方法见[当前交付与启动](当前交付与启动.md)。

## 本次完成

- 普通用户直接用用户名与密码注册，移除邀请界面及邀请 API；保留原账号、权限和注册限流。旧邀请数据仅作历史保留。
- 网页新增“模型设置”，支持 Anthropic Messages / OpenAI Chat Completions、自定义公网 HTTPS Base URL、模型名称及个人 Key，提供 DeepSeek 预设。
- 模型 Key 按用户加密保存；不回显、不进入浏览器 localStorage，插件 Key 无权读取或管理。设置带修订号，修改目的地需重填 Key，防止旧页面覆盖或将旧 Key 发往新地址。
- PDF 默认仅提取文字。用户勾选模型整理后才发送文字，界面显示提供商与模型；上传时固定配置版本。输出经结构校验、人工确认后才成为正式简历。失败仍可手动整理。
- 服务器默认只运行业务 API，不依赖推理容器；不会将服务器的测试 Key 自动共享给用户。Ollama/vLLM 适配器保留为后续可选方案。
- 黑白网页、安装插件入口、简历维护、插件同步与离线填写继续可用。

## LLM 与参考插件

当前模型主要将提取出的 PDF 文字整理为简历结构。手动编辑、保存、同步和插件常规填写由普通业务与浏览器代码完成。字段辅助、基于事实的回答草稿已有后端接口，但尚未接入常规填写流程；润色仍未实现。

参考插件的浏览器代码显示，它调用远端的 `getNeedField`、`fillResumeValue`、`fillBlockResumeValue`、`chooseModalOption` 和 `beautifyResumeMd`，然后按结果寻找和操作网页控件。**这能证明任务交给后端，不能证明各接口都使用 LLM。** 未取得后端实现，无法核实模型、提示词、规则、缓存及网站适配所占比例。详细浏览器端证据见[原插件适配能力与复用评估](原插件适配能力与复用评估.md)。
