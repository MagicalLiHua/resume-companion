# 51job 与大易原站调研及适配顺序

日期：2026-09-21。运行版本：0.24.0+codex.20260921020533。
范围：Resume Companion 专用浏览器，两个 51job 企业模板、中国一汽大易页面。用户确认先研究这两个 51job 样本。
状态：本文件记录开发前的原站结构与有限交互调研。后续实现和验收进展见[开发记录](51job与大易适配开发记录-2026-09-21.md)；下文保留调研时点的证据。

## 1. 样本和操作边界

| 样本 | 当前证据 | 尚未验证 |
| --- | --- | --- |
| 51job 中粮集团模板 | 个人信息页面、侧栏 11 个步骤、可见必填错误 | 后续十个步骤的实际控件、保存/翻页持久性 |
| 51job 测试工程师 J10058 模板，企业名称待确认 | 侧栏 6 个步骤；成功跳过可选附件解析并进入基本信息 | 教育、IT 技能、工作经历、自评的实际控件及最终边界 |
| 中国一汽大易 | 长表、模块导航、学校选择弹窗、Ant Design 旧式控件结构 | 日期选择、选项提交、添加多记录、保存持久性 |

51job 路径为 xyz.51job.com/External/MyResume/FillInResume.aspx；大易为 faw-zhaopin.hotjob.cn 下的 resumeOperation.html。本文不保存带简历标识的完整 URL 或用户已有字段值。

本次未填写任何简历字段、未上传、未勾选声明或点击保存/最终投递。唯一翻页操作是第二个 51job 模板明确允许的“无附件，直接点击下一步”；页面现在停在基本信息。大易打开的学校弹窗已用实际取消按钮关闭，并通过新快照确认消失。没有重启浏览器。

## 2. 51job：已确认的共同结构与企业差异

### 中粮：11 个步骤

个人信息 → 教育经历 → 社团（学生工作、活动）经历 → 实习/工作经历 → 研究项目经历 → 竞赛经历 → 获奖情况 → 语言能力/技能证书 → 家庭成员信息 → 自我评价 → 本人承诺。

第一页涉及出生日期、健康状况、现居城市、籍贯、高考生源地、申请者类别、企业亲属关系等字段，并出现“是否同意提供身份证号码”授权项和照片上传要求。授权、附件和本人承诺不能作为普通资料字段自动补齐。

### J10058：6 个步骤

上传并解析附件简历 → 基本信息 → 教育经历 → IT 技能 → 实习/工作经验 → 自我评价。

第一页明确允许跳过附件。跳过后基本信息包含出生年月、目前居住地、期望工作地点、联系方式、英语水平、其他外语等。出生日期使用两个原生年月下拉框，与中粮的只读日期输入不同。

共同点：字段主要以 DL / DT / DD 组织，多个原生 select 构成城市等联动字段；按钮使用 input[type=submit]，通过 title=Next/Save 标识，页面中呈现为无名称按钮。两份模板都不能仅凭控件 ID 确定字段含义，CCA 等自定义字段必须读取可见标签。

### 已复现的问题

1. **标签读取错误**：姓名在观察中变成 cc_Cname_1_1；出生年月甚至用整串年份/月份选项当标签。应绑定同一 DL 的 DT，并给复合字段分配子角色。
2. **必填和错误遗漏**：中粮页面显示多条“不能为空”，观察返回 validations:[]；错误位于 DD 内 LABEL/FONT，必填标记在 DT。不能只依赖 required、aria-required 或现有 .error 类。
3. **按钮类型错误**：imgbtnNext、imgbtnSave、imgbtnPrevious 被当作文本字段。form_activate(next_step) 对已观察到的 imgbtnNext 返回 target_unresolved；使用已确认的真实按钮 UID 后成功翻页。
4. **附件及非当前控件混入资料字段**：文件选择、上传按钮和日历 iframe 内部输入被列入普通填写字段。需识别 iframe 用途与宿主可见性，不能依赖子 frame 自身尺寸就视作当前简历字段。
5. **同 URL 翻页**：附件页成功进入基本信息后，URL（包括 SeqID）保持不变，标题 h1 从“上传并解析附件简历（可跳过）”变成“基本信息”，侧栏当前项发生变化。本轮观察的 navigation_id 也已变化。执行器不能把 URL 变化作为唯一成功条件。

### 翻页与保存语义

按钮元素为 type=submit，onclick 为 return saveCheck()，页面同时提供 Next 与 Save。已证明可跳过附件进入下一步，但尚未证明其他步骤的“下一步”具体保存了什么、失败如何回显；不能把 HTML submit 类型一概视为最终求职提交，也不能把所有下一步当成无副作用导航。

适配要按当前步骤、按钮用途、后继页面与校验结果区分普通阶段转换和最终投递。在边界未确认时返回明确状态，不盲目继续。

## 3. 大易：长表可以复用执行框架，控件仍需适配

页面导航列出个人基本信息、教育经历、外语能力、项目经验、实习经历、校内职务、技能资质、其他外语能力、家庭关系、自我评价、相关附件；正文另出现科研经历添加入口。

当前观察返回 79 个控件候选，这不是 79 个独立可填写字段：其中包括完整度星级 radio、重复的上传按钮、保存与声明。观察仅返回 6 个有控件的栏目，漏掉尚未新增记录的可选栏目。

只读检查确认的控件类：

- 下拉：ant-select-selection / ant-select-selection--single。
- 日期：ant-calendar-picker-input / ant-calendar-picker，而非当前常见的 ant-picker 系列。
- 添加：add-more-btn 内图标加文字，未提供标准 button 语义。
- 学校：普通 ant-input 外观，点击后出现独立 dialog，包含搜索框、地区/学校列表、取消和选择按钮。不能按普通文本输入即判定成功。

已复现：打开学校选择后，focus 观察返回 overlays:[]，但 locality 正确提示外部结构变化；快照确认 dialog 存在。随后 form_activate(close, target=取消) 返回 overlay=closed，实际 dialog 仍在，出生日期被其遮挡并返回 target_obscured。用最新快照中的“取消”按钮点击后弹窗才真正关闭。

代码对应：form_activate 的 close 分支通用调用 dismissPopup，而未验证指定模态框实际消失。需要区分下拉与模态框，不能用某个触发器未展开替代弹窗关闭证明。

一汽信息要求也比普通简历细：培养方式、是否全日制、学习形式分别存在；还有专业排名、奖学金、挂科、CET 成绩/考试时间/准考证号、家庭关系等。新需求应进入首次补充表规则库，保留语义差异，不自行推断。

## 4. 推荐开发顺序

### 第一批：先修可观察性和结果验证

- 51job：DL 标签、必填星号、字段错误、submit/image/button 类型及 Next/Save/Previous 名称；日期年月分组、城市父子关系、frame 宿主可见性。
- 大易：无记录模块与添加按钮、必填标记、记录范围、评分/附件过滤；模态框打开与关闭后置验证。
- 先做脱离真实用户资料的最小合成控件回归。下一步误判、空字段漏报、关闭假成功必须成为断言，避免再次依赖 Agent 多轮诊断。

### 第二批：大易控件和单页自动规划

- 平台识别结合站点和页面结构，不把任意使用 Ant Design 的网站都识别成大易。
- 适配旧式下拉/日历、学校与专业弹窗、城市联动、重复记录添加、长文本提交与读回。
- 增加系统字段映射，复用现有 profile → facts → prepare → run。附加字段缺少来源时集中报告，不编造。
- 对原站验证 UI 写入与保存分开报告；授权与附件留在人工边界。

### 第三批：51job 当前页计划和跨页协调

现有 FormPlan v1 绑定一次 observation/navigation，只支持当前表单的填写步骤。不要把后续页面尚不存在的控件放进当前计划；在其外层增加可恢复的跨页流程。

1. 开始时固定资料 revision、企业模板身份、可见步骤目录和当前位置，读取已知步骤需求；未知后续字段保留未观察状态。
2. 在本地对当前页做完整观察、事实映射、批量执行、必填/错误校验。
3. 只有满足当前页条件且按钮确认属于普通步骤转换，才执行下一步。
4. 验证标题、当前步骤标记、表单结构与导航状态。仍在原页则分类为校验失败、加载未结束或结果不明，不能直接重复点击。
5. 新页面重新生成字段/记录绑定，沿用资料事实和规则；普通已知页面由本地协调器连续处理，避免每一页让模型重新规划。
6. 检查点记录已验证页、下一步是否发出、后继页是否确认。重连后先确认所在步骤，不能重放未知结果或重复新增记录。
7. 到最终投递、声明、上传或资料缺失时返回明确边界。页面目录可能因条件题变化，不能硬编码固定页数或第 N 步即完成。

跨页预算独立设计，保留现有前台执行窗口、取消和失联停止约束；每页预算与全流程预算不能简单照搬单页 180 秒，也不能仅通过增加超时掩盖循环。

### 第四批：企业差异回归与首次补充表联动

- 两个 51job 模板必须共用驱动并覆盖日期控件差异、步骤差异、可选附件跳过和未开放模块。
- 模板库储存可复用规则及需求证据，不缓存个人值、运行 UID 或之前用户的校验结果。
- 首次补充表按已知需求并集补齐相关事实；同义字段去重，企业亲属关系等保留企业范围。新的未观察页面仍由执行时核对，不能宣布已经覆盖。
- 已完成资料准备后，已知字段不应再因为缺项打断；控件失败、新增企业问题与用户暂缓项分开统计。

## 5. 验收与下一步交付标准

51job：至少验证多页推进、必填阻断、同 URL 替换表单、联动、日期、重复经历、返回/恢复、下一步结果不明时不重放，以及最后边界不误提交。当前没有查看到的后续页面需要在授权测试资料下补充真实证据，不能按侧栏文字推断已适配。

大易：验证学校/专业选择提交、旧式日历、父子下拉、多记录隔离、空模块添加、长文本保持、对话框关闭验证、必填及错误读取。保存成功和刷新持久性需要单独验证。

性能记录区分资料准备、页面加载、模型等待、当前页执行、翻页、最终检查。目标是规则覆盖后的多页处理不再逐页请求模型编排，不承诺未经实测的总时长。

通过上述验收后，才可把产品支持范围称为五类系统（飞书、Moka、北森、51job、大易）的已验证模板适配；不能把本次查看页面算作新增两类适配完成，也不能据此宣称覆盖每家企业的全部定制。

- plugins/resume-companion/src/browser/planning/recipes.ts、compiler.ts：平台/字段映射与当前页编译。
