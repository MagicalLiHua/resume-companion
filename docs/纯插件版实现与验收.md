# 纯插件 0.4.0 实现与验收

日期：2026-09-11。本文记录实际实现和验证，覆盖用户最终确定的首版范围：多版本、本地补充资料、Markdown 导入、真实模型辅助、自动悬浮窗口、轻量投递记录与安装包。真实网站试用由用户明确后移。

## 已交付能力

| 功能 | 实现结果 |
| --- | --- |
| 多版本简历 | 最多 30 份，可新建、复制、重命名、切换、删除；各自保留正式资料和上一份 |
| 资料与补充表 | 基本信息、教育、工作/实习、项目、技能、证书、固定回答及自定义补充字段；未知状态与否分开 |
| Markdown 导入 | 固定模板、复制提示词、UTF-8 文件/文本输入、行号和问题定位、差异预览、历史原文与日期精度保留 |
| 草稿与正式保存 | 自动草稿、关闭恢复、多窗口接管、修订冲突检查；未保存内容不用于填写 |
| 备份迁移 | 完整备份保存全部版本、补充表、原文、草稿、上一份、投递记录与非凭证设置；兼容旧 JSON，单独草稿可重新导入 |
| 模型配置 | 用户自带 Key，Anthropic / OpenAI 兼容协议；连接测试、会话保存/本机记住、目标校验和清除 |
| 模型字段辅助 | 仅发送核对过的字段与来源说明，校验候选引用；失败继续手选，不把模型生成值写入简历 |
| 自动悬浮窗口 | 普通招聘网页右下角入口，选择本次版本、自动扫描、核对后确认填写；与侧边栏复用逻辑 |
| 页面填写 | 已有值保护、经历绑定、预览失效、回读和有条件撤销；不自动提交 |
| 投递记录 | 独立页面，记录公司、岗位、网址和时间，搜索/筛选/编辑/删除/CSV/JSON 导出与统计；无逐条确认流程 |

版本选择不会改变另一份简历的内容；网页填写选择另一版本，也不会修改资料页里未保存的草稿。补充资料按版本维护，复制时一并带入，重新导入简历不会清空手工补充表。

自动记录只观察插件扫描后的页面提交动作与随后可识别的成功提示，同一扫描会话去重。记录默认“已记录”，直接计入统计；这是页面操作记录，不宣称已验证招聘网站的实际提交成功。无法识别的公司/岗位可留空或手动编辑。

## 数据与权限

- `chrome.storage.local` 使用版本化容器，正式状态统一提交；草稿有独立修订与编辑实例，多窗口不能静默覆盖。
- 正式资料每份 1 MiB，本地总预算 8 MiB，超过限制报错，不截断或先删除旧内容。投递记录最多 1000 条，单条备注最多 2000 字符。
- 旧版资料迁移先写入并读回核对，再移除旧存储与业务连接凭证。更新保持扩展 ID 和加载目录，保持开发者模式开启并重新加载。
- 自动悬浮入口使用用户已批准的 HTTP/HTTPS 网页权限，仅顶层自动注入。模板、资料、草稿与模型 Key 不直接提供给网页内容脚本。
- 悬浮窗口使用扩展页面及每页会话令牌，网页自行嵌入的伪造 iframe 不能读取资料。模型 Key 只在可信扩展上下文中使用。
- 模型通过 HTTPS 直连用户配置的服务，禁止携带网页 Cookie 和跟随重定向；有超时、输出大小和格式校验。应用不请求旧业务后端或遥测。

## 安装文件

`artifacts/resume-companion-0.4.0.zip` 及旁边的 `.sha256` 校验文件。解压后在 Chrome 开发者模式加载其中的 `extension`。本机可直接加载 `dist`。

安装包包含运行资源、安装说明、模板、提示词、验收摘要及第三方许可，不含真实简历、模型 Key、测试脚本、Python 或 Electron 依赖。实际包内核对见 [发布检查](../artifacts/package-audit-0.4.0.json)。

## 明确后移与限制

- 按用户要求先交付安装包，国聘、智联等登录后真实页面留待后续试用；没有把合成页或参考插件代码当作网站兼容证明。
- Edge / Windows 未实际复测，当前验证环境为 macOS、Chrome for Testing 151。
- 复杂下拉、地区级联、文件上传、跨域 iframe、Shadow DOM 内控件等仍可能需要手工处理。
- 某些自定义提交按钮不产生原生提交事件，或者跳转后的成功提示无法观察，投递记录需要手动补记。
- 新版完整备份不能直接当作旧版 1.0 JSON 使用；回退使用升级前导出的旧备份。
- 原网页与后端作为历史成果保留，没有在本轮部署、停用或清理线上数据。

源码快照保存在 `.checkpoints/before-pure-plugin-20260911-110533.tar.gz`，随附 SHA-256 清单。完整工作区没有预先存在的 Git 仓库，本轮采用该快照保留开发前基线。
