## 已交付功能

- `/v1/fields/resolve`：受控来源目录与规则优先，未匹配字段交由模型建议；歧义或受限字段放弃，字段值仍由插件本地读取。
- `/v1/answers/draft`：仅接收选定事实，返回待复核草稿与事实引用；事实不足时不生成回答。
- `/healthz`、认证后的能力、模型就绪、来源目录及 OpenAPI 接口。
- Bearer 凭证摘要存储、独立用户限额、即时撤销、严格 Host/Origin 与正文校验、统一无输入回显的错误。
- 全局 2 个在途任务、每凭证 1 个；45 秒业务总预算、30 秒单次模型调用、最多一次格式修复、断开后有界收尾。
- Ollama 适配、启动后台预热、模型驻留、请求/响应大小和上下文预算限制。
- Mock 开发模式、共享 JSON Schema/TypeScript DTO、请求构造与响应引用校验、离线部署、管理脚本与发布包。

令牌当前由管理员通过命令行创建。没有自助注册页面或数据库，也没有把插件中的完整简历同步至服务器。当前扩展安装包仍是本地 v0.1.0，浏览器 AI 调用及新的网页端工作流尚待接入。

## 已有模型实验与边界

样例在查看真实输出前冻结：200 个字段（160 个可回答、40 个歧义/受限项），30 个草稿场景，20 轮双并发共 40 次请求。它是合成回归集，存在模板重复；没有按真实站点划分独立保留集，不能代表招聘网站兼容率。

| 历史配置 | 建议正确 / 所有建议 | 可回答项正确 / 160 | 草稿协议与状态 | 双并发成功 |
| --- | --- | --- | --- | --- |
| 首轮提示词 | 115 / 116（99.1%） | 115 / 160（71.9%） | 30 / 30 | 40 / 40 |
| 增加目录提示和动态约束的实验 | 74 / 75（98.7%） | 74 / 160（46.3%） | 30 / 30 | 40 / 40 |

首轮 20 个字段请求中有 1 个因非法输出返回 502；也出现过将“就读学历”建议为学位的错误。第二次实验没有改善覆盖率，未采用其额外提示和动态约束。最终版本保留规则优先及已知语义校验，模型不能替代已经确定的学历等来源。

首轮 10 字段批次 P95 约 6.34 秒，短草稿 P95 约 1.13 秒，双并发短草稿 P95 约 2.03 秒；单次 40 字段批次约 14.27 秒。草稿实际多为几十字，不能把这些结果当成 300 字输出或最大负载的延迟保证。40 字段只执行过单次最大批次检查，没有最大批次 P95 结论。

首轮逐项检查返回草稿，未发现新增学历、证书、年限或未提供的量化成果；仍存在“精准”等强化表述，全部草稿需复核。协议校验和事实 ID 引用不能证明所有自然语言忠实性。

完整失败案例没有删除：[首轮实验](../artifacts/backend-evaluation-baseline.json)、[目录约束实验](../artifacts/backend-evaluation-scoped-catalog.json)。[评测索引](../artifacts/backend-evaluation.json) 区分历史实验与最终代码。依用户要求不再运行当前小模型的全量调优；覆盖率目标尚未达到，不宣称 M6 完整验收通过。

## 离线部署与交付物

基础 Python 镜像在有网电脑下载，清单摘要与 Docker 官方元数据匹配，配置、压缩层和解压层摘要均已核对；Python wheels 按生产锁文件哈希下载。服务器经 SSH 接收文件，Docker 构建禁止网络，pip 使用 `--no-index --require-hashes`，运行时不访问外部模型服务。

- 源码包：`artifacts/resume-companion-backend-0.2.0.tar.gz`。
- 离线包：`artifacts/resume-companion-backend-0.2.0-offline.tar.gz`，附 Python 基础镜像和 Linux 生产依赖。
- 两个包各有 SHA-256 文件和包内逐文件摘要，不含 `.runtime`、个人令牌、真实简历、虚拟环境或模型权重。
- [后端使用与维护](../backend/README.md)、[离线安装与恢复](../backend/OFFLINE.md)。

已有 Ollama 镜像与权重由服务器提供，不重复打进离线包。评测专用的两个凭证已撤销，owner 凭证保留在本机 `backend/.runtime/owner.token`，发布包不包含它。命令行令牌注册表仍按每用户一个凭证设计；下一阶段的自助多 API Key 管理需要新的持久化数据结构。

当前限额保存在单进程内存，服务重启会重置。API 只监听回环端口；进程健康不代表模型就绪，应使用认证后的就绪接口。服务通过 Docker `unless-stopped` 恢复，SSH 隧道需使用者电脑保持运行或重新建立。
