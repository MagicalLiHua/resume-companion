# 当前交付与启动（后端 0.4.0 / 插件 0.3.2）

更新：2026-09-11。已部署用户自带模型版，支持直接注册和个人模型 API。源码与安装包均在本项目内；本文件不含实际密码或密钥。

## 打开网页

当前服务部署在 `10.160.108.2`，通过本机 SSH 通道访问 [简历工作台](http://127.0.0.1:18080)。通道正在运行时直接打开即可；电脑重启或断网导致通道退出后，在终端重新执行并保持窗口打开：

```sh
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -L 127.0.0.1:18080:127.0.0.1:18080 user2@10.160.108.2
```

如果提示本地端口已占用，先检查网页是否已能打开，不要重复启动通道。

管理员用户名为 `administrator`。随机初始密码只保存在本机 `backend/.runtime/web-admin-password.txt`（权限 600），不在发布压缩包内。首次登录后可在账号设置修改密码；不要将该私有文件分享给试用者。

## 网页安装入口

网页已改为黑白配色。登录页和左侧栏的“安装浏览器插件”，以及“连接插件”页的“在当前浏览器安装”，都可打开安装指引。安装包由当前服务直接提供，服务器无需外网。内测版尚未上架商店，下载 ZIP 后按指引在电脑版 Chrome / Edge 加载其中的 `extension` 文件夹。

## 从简历到填写

1. 点击“注册账号”直接注册，或使用已有账号登录；无需邀请码。
2. 手动新建简历，或上传文字 PDF。需要模型整理时，先在“模型设置”填写自己的提供商与 Key，再在上传页勾选“使用我的模型整理简历”；默认只提取文字。核对后保存正式版本。
3. 在“连接插件”创建个人 API Key，复制完整值。
4. 在网页点击“安装浏览器插件”下载安装包并解压，也可使用 `artifacts/resume-companion-0.3.2.zip`。Chrome 的 `chrome://extensions` 开启开发者模式，加载其中的 `extension` 文件夹。
5. 插件中打开“连接网页账号与同步”，填写 `http://127.0.0.1:18080` 和自己的 Key；允许该地址权限后，检查差异并同步。
6. 在目标网页点击工具栏插件、扫描、核对来源和经历，再确认填写。同步后的资料可离线使用。

完整迁移、缓存清理和填写范围见[安装与体验](../安装与体验.md)。多台电脑/多人内网入口尚未配置，不能把上述本机地址直接当成其他电脑的服务器地址；确认实际访问方式后再配置 HTTPS 入口。
