# 简历随行插件 0.3.2 安装与体验

网页后端版本为 0.4.0，普通用户直接注册，并可配置自己的模型提供商 API。插件 0.3.2 增加 Lever 申请表标题识别和必填标记修复，公开页仅做只读验证；详细范围见同目录中的《公共表单适配记录》。插件 0.3.1 修复更换服务器时的旧主机访问权限清理；同一主机换端口保留授权，以免影响当前连接。

## 网页维护与同步

1. 打开管理员提供的网页地址。管理员首次账号由服务器命令行初始化，没有公开默认密码。
2. 普通用户点击“注册账号”，填写用户名和 12–128 位密码，无需邀请码。
3. 在“我的简历”新建并填写，或到“PDF 导入”上传可复制文字的 PDF（最大 10 MiB、30 页）。默认只提取文字；需要模型整理时先在“模型设置”保存自己的提供商 API Key，并在上传页勾选使用模型。逐项核对后确认保存；解析失败时可对照原文手动整理。
4. 可以命名、复制简历、设置默认版本。保存时检查修订号，发生冲突不会覆盖另一页已保存的内容；可以先导出当前编辑内容，再返回重新载入。
5. 在“连接插件”创建 API Key，复制只显示一次的完整值。
6. Chrome 打开 `chrome://extensions`，开启开发者模式，加载解压包的 `extension` 文件夹；开发目录也可直接加载 `dist`。
7. 打开插件的“连接网页账号与同步”，填写网页服务地址和 API Key，在 Chrome 中允许访问这个服务地址。
8. 确认账号后选择简历，检查与本地资料的差异，再点击“确认同步”。每次网页修改后再次同步。
9. 在目标招聘网页点击工具栏插件，扫描当前页、检查拟填内容、绑定多段经历，再填写选中字段。申请由用户自己提交。

服务地址支持 HTTPS 或本机 `127.0.0.1` / `localhost` 的 HTTP 地址。当前私有部署可通过既有 SSH 隧道访问 `http://127.0.0.1:18080`；隧道需要保持运行。

## 更新与回退插件

更新前主动导出 JSON 备份，并记住 Chrome 扩展详情中当前加载的目录。将新包的 `extension` 内容替换到该目录，回到 `chrome://extensions` 点击该扩展的重新加载按钮，再刷新招聘页面并重新扫描。开发目录使用者保持加载同一个 `dist` 目录即可。不要通过卸载扩展来更新，以免删除本地存储。

0.3.0、0.3.1 和 0.3.2 使用相同扩展 ID 与简历数据版本，更新后仍需检查连接账号和资料。需要回退时，将此前保存的版本包放回同一目录，重新加载扩展和招聘页。网页保存的简历不受插件文件替换影响；如本机资料无法加载，可在插件明确恢复备份，或重新连接网页账号并核对同步。

若连接或清理账号时已经主动删除本地缓存，回退程序版本不会恢复这些缓存；请使用自己导出的 JSON 或网页上的正式简历。更新及回退后，旧页面的填写预览和撤销记录均不继续使用。

## 本地资料迁移与断开连接

首次连接或更换账号会清除旧本地简历、备份和密钥。需要保留旧资料时先在插件导出 JSON；到网页“我的简历”导入并检查，确认后创建新简历。插件不会静默上传浏览器里全部资料。

断网时仍可填写上次同步的本地简历，界面显示最后同步时间。密钥失效时需重新创建，已同步的离线缓存不会自动删除；使用“断开连接”才会清理该账号在插件里的缓存和密钥。网页资料继续保留。

只在插件本地编辑的修改不会自动写回服务器；需要上传时导出 JSON 后在网页确认导入。再次同步前请检查差异。

## 当前填写范围

支持普通输入、原生选择、单选组、年月及明确的技能复选框。多段教育或经历需用户指定对应关系，区分已获学位与预计学位；默认保留网页已有内容。填写后回读；页面或资料变化会使旧预览失效。

复杂控件、地区级联、iframe、Shadow DOM 和特殊证书字段暂需手填。合成表单通过验证，真实招聘网站仍需逐站实测，不能据此承诺所有网站适配。

插件不会自动提交、点击下一步或勾选同意协议。“撤销”只能恢复仍符合预期的网页当前值，无法撤回网站自动保存的请求。
