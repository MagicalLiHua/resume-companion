## 实现边界

- 正式简历存入私有服务器，插件仅同步用户确认的版本。网页会话使用 HttpOnly Cookie，写操作验证 CSRF；API Key 不可编辑简历。
- PDF 最大 10 MiB、1–30 页；提取程序独立进程，限制 CPU、Linux 内存、输出和执行时间。扫描件无 OCR 时明确提示，不将空文字当作成功。
- 解析模型只尝试一次；失败或文字过长时保留完整提取文字供手动整理。用户明确核对并保存后才生成正式简历。
- 上传与解析最多同时 2 个任务，每个用户 1 个；同一天保留最多 10 个未删除导入。上传任务及原始 PDF 24 小时后清理，已确认简历继续保留。
- 已同步资料可离线填写。首次连接和更换账号均先提示导出旧本地资料，确认后清除旧缓存；API Key 保存在可信扩展存储，内容脚本无法读取。
- 插件使用固定公开 manifest key 取得稳定 ID；服务端允许列表需配置此 ID。服务地址权限在用户连接时单独申请，不默认获取所有网页权限。
- vLLM 适配使用固定服务地址、服务端凭证、`/v1/models` 和 `/v1/chat/completions` 的 JSON Schema 输出。实际模型部署、量化与效果留待后续，不因此阻塞维护功能。
- 字段模型辅助和开放问答的后端接口已保留，插件没有启用这些按钮。按照用户早先的决定，AI 增强继续后置；现有填写依赖本地规则和用户预览。
