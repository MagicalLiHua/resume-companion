## 3. 验收场景

### 3.1 Markdown、事实和转换

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| A01 | 标准单段与多段模板 | 每个已提供字段、经历归属和顺序与人工预期一致 |
| A02 | 缺失字段、空列表、空经历 | 空值保持未知；不创建虚假经历或默认本科/在职 |
| A03 | CRLF/BOM、加粗标签、不同冒号、别名 | 允许的变化得到相同语义结果和正确行号 |
| A04 | 多行工作/项目内容、引号、冒号 | 内容保留为文本，不截断或错分成新字段 |
| A05 | 年份、年月、完整日期、至今、预计 | 日期精度保留，不补造月/日；状态冲突阻塞 |
| A06 | 在读、已获/预计学位、未知类型 | 不混淆预计与已获，未知布尔/类型不当成明确事实 |
| A07 | 相同字段重复且不同值 | 显示双方位置与冲突，不能最后值覆盖 |
| A08 | 未知章节、表格和自由段落 | 保留原文、指出无法映射位置，不声称全部解析成功 |
| A09 | 围栏外解释、多个代码块、未知版本 | 需要用户整理或选择，不偷偷取第一份 |
| A10 | HTML、脚本、远程图片、恶意链接 | 仅作文字，不执行、不请求外部资源 |
| A11 | 256 KiB 边界、超长字段、大量嵌套 | 按限制拒绝或定位，页面可响应，现有资料不变 |
| A12 | 当前资料导出 Markdown 再导入 | 支持字段语义、日期精度和未知状态保持；补充内容不丢失 |

### 3.2 编辑、保存、备份与迁移

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| B01 | 解析预览但不应用/不保存 | 正式资料与填写来源不变 |
| B02 | 重新导入删除原有字段和经历 | 差异明确显示删除，未经确认不应用 |
| B03 | 修改 Markdown 后使用旧预览 | 阻止旧结果应用，要求重新解析 |
| B04 | 表单修改后回看原文或生成新 Markdown | 原文标记历史来源；当前导出反映最新正式值 |
| B05 | 草稿自动保存、切换页签、关闭/重开 | 可恢复最近完成保存的 Markdown/表单缓冲，导航不清空未保存内容；不冒充正式保存 |
| B06 | 两个编辑标签页或正式资料被另页修改 | 正式保存和草稿保存均有冲突保护，不静默覆盖 |
| B07 | 本地配额不足/模拟存储失败 | 明确报错，当前正式资料、原文及上一份保持可恢复 |
| B08 | 浏览器重启与后台休眠 | 正式资料仍存在，重新打开可继续编辑和填写 |
| B09 | 完整备份导出、恢复、损坏和未来版本 | 有效备份按确认范围恢复，文件中的正式版/上一份均可选择；恢复前当前版本成为本地上一份；无效备份不改现有数据 |
| B10 | 旧 JSON、旧插件的单机/已同步资料升级 | 旧字段、经历、备份可用；不请求服务器、不连带清掉资料 |
| B11 | 升级中断、迁移失败、空间不足 | 旧存储可读、迁移可重试；只在成功验证后清理凭证 |
| B12 | 清除资料、恢复上一份 | 用户明确操作，修订更新、旧预览失效；完整备份文件不受影响 |

| C12 | 键盘、缩放、窄侧栏、长文本 | 控件可访问、文字不遮挡，关键操作有明确状态 |

### 3.5 补充资料与字段匹配（P0）

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| E01 | 补充资料新增、编辑、删除、空值和内容超限 | 正式保存后生效；稳定 ID 不因改名称或排序变化；空值不填，超限不截断 |
| E02 | 补充资料草稿、关闭重开、多窗口修改 | 与其他资料共用草稿及冲突保护；未保存值不参与填写 |
| E03 | 已维护补充表后重新导入 Markdown 或旧 1.0 JSON | 更新简历章节，保留当前补充草稿；预览期间草稿变动使旧预览失效 |
| E04 | 含补充资料的完整备份、上一份恢复、旧版迁移 | 完整备份可往返，恢复范围明示；旧版首次迁移得到空补充表 |
| E05 | Markdown 补充信息和手工补充表同时存在 | 原文不自动转为填写值；简历 Markdown 导出范围明确，手工表通过完整备份迁移 |
| E06 | 不同公司将手机字段写成手机号、联系电话等 | 明确别名在相容分组指向同一正式来源，显示匹配依据 |
| E07 | 现居地、籍贯、户籍所在地、生源地；申请人/联系人姓名 | 含义不同不合并，分组明确冲突时不退回跨组匹配 |
| E08 | 陌生字段名、同名补充项、多个经历、重复来源 | 歧义要求手选或经历绑定；本次选择不自动推广到其他公司或后续会话 |
| E09 | 补充资料映射到受限字段、不支持控件或不唯一选项 | 手动选择及匹配器均不能绕过现有限制；补充表不扩大复杂控件支持范围 |
| E10 | 可替换匹配器返回越界、重复字段或不一致状态/候选 | 统一校验拒绝；匹配结果不携带资料值、DOM 操作或可执行指令 |
| E11 | 匹配器取消、超时；匹配期间资料或页面变化 | 在途旧结果失效，不执行；保留有效本地结果和手动选择入口 |
| E12 | 断网完成资料维护与本地匹配；使用测试替身替换匹配器 | 本地能力无模型网络或 Key 依赖；正式包包含生产模型适配器，不混入测试替身或 Key |

### 3.6 纯插件模型辅助（P0）

| 编号 | 场景 | 通过条件 |
| --- | --- | --- |
| G01 | 模型设置、按域名授权、拒绝/撤销权限 | 只有主动连接才申请该域名；拒绝后不调用，本地资料可用 |
| G02 | DeepSeek Anthropic 在真实扩展页面请求 | 用户自带 Key，真实 `/anthropic/v1/messages` 响应通过结构和语义校验，无业务后端 |
| G03 | OpenAI 兼容格式与提供商差异 | 协议组装、地址前缀、响应与能力差异分别验证；只对实际测过的服务/模型声明兼容 |
| G04 | 更换地址/协议/模型、重定向或非法 URL | 凭证不自动发送给新目标；配置更新使旧建议失效；重定向及不合法目标拒绝 |
| G05 | 会话/记住 Key、重启、导出备份与清除设置 | Key 只在可信区域；不进入源码、包、日志、报告和资料备份；清除模型配置不删简历 |
| G06 | 发送内容预览、排除字段、描述中夹带个人信息或指令 | 实际请求与确认内容一致；不含真实资料值、网页现值、整页 DOM 或其他凭证；描述只作为数据 |
| G07 | 返回猜测值、未知/重复来源、跨组候选、错误 JSON | 严格拒绝越界结果，不把模型值写入资料或网页；真正歧义可以弃答 |
| G08 | 请求期间导航、重扫、改资料、改来源选择、改发送内容、改配置或关闭侧栏 | 取消并丢弃旧结果，不能覆盖用户更新或新会话 |
| G09 | 超时、401/403、限流、断网、超长响应及输出修正 | 明确错误、有限请求预算，不自动无限重试；有效本地结果和手选可继续 |
| G10 | 未配置 Key、模型未启用、所有后端关闭或断网 | 导入、补充资料、编辑、备份、本地匹配与填写完整可用；不自动请求模型 |
| G11 | 内容脚本/网页尝试读取 Key 或借消息调用模型 | 拒绝读取和调用，不提供任意 URL 转发或通用执行接口 |
| G12 | 模型建议 → 核对 → 填写 → 回读 | 用户确认后才写入；不自动提交；记录实际模型、耗时、用量、错误和弃答情况 |

## 4. 数据集与测量方法

至少准备三份人工标注的合成简历：单段经历、多段经历、字段缺失。每份覆盖相应状态和时间；由模板派生输入格式变化及错误案例，预期值单独标注，不能只用被测转换器生成期望结果。

固定填写样本复用现有 20 类、200 个标注字段，并加入未知状态、补充资料、异名同义、同名异义、重新导入后旧绑定失效等新增场景。真实扩展测试使用独立浏览器配置，不混用开发者日常登录资料。

性能测量记录设备、浏览器、插件版本、样本大小和测量方式；典型样本重复运行至少 20 次，记录 P50/P95。结果未达到目标时记录实际值与改进方案，不能只展示最快一次。

真实网站覆盖与执行正确率分别记录分子分母；不支持或资料不足的字段列出原因，不通过排除误填来美化结果。首版发布不能包含已知会错误填写的适配分支。

模型评测单独记录来源识别正确率、错误建议和未匹配/歧义数量，弃答不计正确命中；安全负例要求零越界执行。合成字段至少覆盖别名、近义改写、同名异义、缺少资料、多段经历和提示注入。现有 10 例直连探针仅是可行性证据，不替代 T22–T24 或真实网站验收；复用同一批样本测试两种协议不能把独立样本数翻倍。
