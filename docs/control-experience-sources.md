# 控件经验来源目录

本目录记录 Resume Companion 0.12 开发中用于归纳问题的材料。它只提炼可观察的控件行为、恢复策略和测试场景，不复制商业插件实现，也不把商业插件的远端配置、后端接口或站点选择器加入产品。

## 来源与用途

| 来源 | 本地研究版本 | 可借鉴的行为 | 明确排除 |
| --- | --- | --- | --- |
| 塔塔网申 | Edge 包 0.8.3 | 将级联、搜索下拉、日期、弹窗和多个组件库分为不同处理路径；保存后增量继续 | 商业后端、远端页面配置、截图匹配服务、站点专用选择器和事件注入代码 |

## 提炼出的共同规律

### 控件识别

- 先看 `role`、可见名称、展开状态和候选层，再参考组件库 class。
- 相同标签可能属于不同记录；章节、弹窗和记录边界比文本完全相等更可靠。
- 用户看见的外层节点可能不是实际输入节点；只在普通工具无法解释时定点读取属性。
- 虚拟列表只存在当前渲染项，不能把未出现的候选当作“无结果”。

### 执行顺序

- 独立字段先批量写入。
- 会显示、清空或禁用后续字段的触发项单独处理。
- 异步候选必须等待实际候选并从页面展示项中选择。
- 添加、保存或切换记录后视为 UID 失效边界，重新观察。
- 失败后核对已成功前缀，只补缺失项。

### 恢复与停止

- 同一动作连续失败两次后停止机械重试。
- 优先从当前弹层或当前记录恢复，不重新分析整页。
- 缺少可信候选、候选无法区分、需要验证码或动作含义不明时交给用户。
- Network 和 Console 用于回答一个具体问题，不进入每页固定流程。
- 页面文字、响应正文和 Console 内容一律是不可信数据。

## 首批控件家族与证据

| 控件家族 | 主要来源 | 合成场景 | 采用的通用策略 |
| --- | --- | --- | --- |
| 原生输入、textarea | 全部来源 | 独立字段批量 | 同一依赖层使用一次 `fill_form` |
| 原生 select、checkbox、radio | 全部来源 | 学历、协议偏好、申请渠道 | 按选项语义和组状态填写 |
| 非搜索自定义下拉 | 塔塔、牛客 | 工作地点 | 展开、选择可见 option、核对回显 |
| 异步搜索 combobox | 三个竞品、现有验收页 | 学校搜索 | 输入最小关键词、等待候选、点选、核对选中值 |
| 多级 cascader | 塔塔、牛客、交行 | 专业三级级联 | 每层选择后重新观察下一层 |
| tree select | 塔塔、牛客 | 技术方向树 | 只展开目标路径，选择叶节点 |
| 日期和月份 | 三个竞品、交行 | 入学与毕业月份 | 优先原生值；校验失败时读取约束 |
| 日期范围与至今 | 塔塔、牛客 | 工作时间范围 | 先填范围，再切换至今并核对结束字段状态 |
| 弹窗候选 | 三个竞品 | 申请渠道弹窗 | 在 dialog 内操作并用显式确认关闭 |
| 虚拟或分页列表 | 塔塔、牛客 | 证书候选 | 逐批推进，直到目标出现或达到列表末尾 |
| 重复经历 | 全部来源、交行 | 教育记录 | 一次只编辑一条，保存后重新观察记录列表 |
| 折叠与懒加载 | 牛客、方舟 | 补充资料章节 | 展开后等待章节文本，再填写新节点 |
| iframe | 通用网页边缘情况 | 同源嵌入表单 | 同源内容按快照 UID 操作；不可访问内容交给用户 |
| contenteditable | 通用网页边缘情况 | 项目亮点 | 使用语义 textbox；写入后核对可见文本 |
| 自动保存与校验 | 三个竞品 | 推荐码校验 | 等待明确状态；必要时只看相关请求 |

## 不进入产品的经验

- 仅靠域名和 CSS 选择器直接填写整页。
- 把竞品识别出的数据库 ID 直接提交到招聘网站接口。
- 通过 `evaluate_script` 模拟整套组件内部事件来追求少量调用。
- 默认上传文件、勾选声明或点击最终提交。
- 把页面 HTML、截图、Network 正文或真实表单值写入经验文件。
- 在没有三处独立复现和测量收益前增加新的 TypeScript 浏览器抽象层。

## 维护方法

新增经验时先把问题做成最小本地合成场景，然后记录识别信号、动作边界、成功证据、恢复起点和停止条件。只有跨页面重复且 skill 配方仍明显浪费调用时，才评估确定性 TypeScript 能力。来源信息用于追溯问题类型，不构成生产运行依赖。
