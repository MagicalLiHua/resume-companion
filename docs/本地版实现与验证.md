# 本地版实现与验证

记录日期：2026-09-10。版本：0.1.0。用户确认开始实施后，已完成 M0 的本地样本、M1 的资料与扩展骨架、M2 的通用表单闭环。真实网站、正式浏览器中的工具栏交互、跨系统体验和长期试用仍待验证。

## 已实现

| 模块 | 实际行为 |
| --- | --- |
| 简历编辑 | 基本资料、多段教育/经历/项目、技能、证书、固定回答；记录 ID、顺序、年月和进行状态 |
| 保存与导入 | 本机存储、修订冲突保护、上一份备份、JSON 差异预览、文件大小及格式校验；未知版本保留原数据，不尝试猜测迁移 |
| 页面扫描 | 用户主动注入；仅当前主文档；读取可见字段标签、值、选项和分组；敏感字段当前值不进入快照 |
| 来源匹配 | 明确别名和分组；多段经历需要绑定；不推断最高学历，不把预计学位当成已获学位 |
| 预览与写入 | 手选来源、修改预览、只填空值、明确覆盖、逐项回读、字段结果与定位 |
| 失效与撤销 | 文档/扫描标识、DOM 结构变化、标签页变化、资料更新、重复操作、旧值冲突保护；有条件回退 |
| 权限 | activeTab、scripting、storage、sidePanel；无全网站常驻脚本、无服务器或模型请求 |

内容脚本只获得选中字段的写入值，不能读取完整简历存储。简历使用 `chrome.storage.local` 保存，非云同步。当前没有设置密码或本地加密。页面自身仍可能监听输入并自动保存，插件无法撤回网页已经发送的请求。

## 字段目录与支持边界

字段目录及别名的实现入口为 `extension/src/domain/rules.ts`，资料结构为 `extension/src/domain/profile.ts`。

| 资料组 | 可作为填写来源的内容 |
| --- | --- |
| 基本资料 | 姓名、邮箱、手机号、现居城市、求职意向 |
| 教育 | 学校、专业、就读学历、已获学位、预计学位、学习形式、入学/毕业年月 |
| 工作/实习 | 单位、职位、开始/结束年月、工作事实文本 |
| 项目 | 名称、角色、开始/结束年月、技术栈、项目事实文本 |
| 技能 | 文本清单、技能分组中与已保存技能精确对应的复选框 |
| 固定回答 | 用户保存的标题和正文；标题一致时建议，否则手选 |

证书可编辑、导入和导出，本版没有专用填写映射。进行状态保存在资料中，网页上的“至今”等特殊控件暂需手填。

通用支持：可见的普通文本/邮箱/电话/多行文本、原生单选下拉、原生单选组、年月、明确的技能复选框。完整日期必须有真实的日，不能从年月补造；搜索下拉、地区级联、多选选择器、富文本、iframe、Shadow DOM 等暂不执行。密码、验证码、证件、银行卡、附件、协议和声明等均跳过。

## 样本与本轮结果

- `contracts/fixtures/resume-single.json`、`resume-multiple.json`、`resume-missing.json`：三份合成资料。
- `tests/fixtures/cases.json`：20 类布局/控件场景，每类 10 个独立标注目标字段，总计 200 个。覆盖标签绑定、ARIA、占位提示、英文属性、全角标点、分组、表格、逆序、窄屏、选项编码、单选组等。
- `tests/fixtures/index.html`：完整仿真网申，包括两段教育、工作、项目、技能、现有敏感值、声明和结构变化操作。
- `tests/fixtures/controlled.html`：真实 React 受控字段，分别接受和拒绝外部写入。

测试环境：macOS arm64，Node 24.15.0，Chrome for Testing 151.0.7922.34，Playwright 1.63.0。详细机器报告运行后生成于 `test-results/results.json`。截图位于 `artifacts/screenshots/资料编辑.png` 和 `填写预览.png`。

浏览器测试用独立临时配置加载真实构建。为模拟用户点击工具栏所获得的页面权限，测试复制构建并**仅在测试副本**中增加 `http://127.0.0.1/*` 权限，侧栏以扩展页面标签打开。发布清单保留 `activeTab`，没有该权限。自动化未覆盖用户正式 Chrome 中物理工具栏点击授权及原生侧栏容器布局，应在首次加载体验时补充检查。

200/200 是固定合成样本上的结果，不能外推为真实网站准确率；未测 Vue 专有组件、真实招聘页、Windows、浏览器重启后的完整人工流程，也未单独采集 P95 性能。没有进行真实投递或修改真实招聘账户资料。

## 后续顺序

先用当前本地版检查自己的资料与填写体验，再开展真实站点只读结构调查和适配。首轮从国聘、智联、前程/应届生的既有线索选择两个代表流程，数量不是支持上限；具体流程在该阶段确定即可。

FastAPI 模拟后端、模型辅助、开放问答和私有服务器仍按计划后置。Word/PDF 自动导入暂缓。当前项目没有复制原商业插件的业务脚本；安装包保留 React、React DOM、Scheduler 和 Zod 的第三方许可。
