# 真实页面结构衍生的离线表单

2026-09-20 从用户已登录的三份简历页采集：Moka（金蝶）、飞书招聘（字节跳动）和智联。先采集当前展开字段，再逐个点击新增入口补采动态表单；智联新建教育草稿选择“本科”以观察依赖字段。采集只保留结构与静态标签，未保存或提交真实资料；新增草稿均已取消。Moka 首次读取超时，经用户确认后刷新恢复；智联地区初始弹层由用户手动打开。

这些页面用于复现字段识别、控件结构和常见交互，不是原站完整前端运行包，不用于证明真实网站的所有受控状态、服务端校验或保存行为已兼容。

## 数据与边界

- 原始捕获结果已在浏览器内按白名单脱敏，位于 `.local-archive/captures/2026-09-20/`。v2 补采保留原始结构 ID、`name`、`data-form-field-*`、标签关联、ARIA、输入约束及部分影响显隐的内联样式；不导出输入值、链接参数、脚本、Cookie 或存储。
- 生成页、脱敏 DOM 模板和候选数据位于 `.local-archive/offline-sites/`。两个目录均被 Git 忽略。此目录中的运行逻辑、测试代码和样式是本项目编写的。
- 字段及编辑记录使用原站捕获的外层 DOM 模板；飞书的收起模块也使用真实模板。字段根节点直接放回原有位置，不再包额外字段 div、添加字段标题或改写 ID。飞书原站已有的重复 ID 保留，测试身份使用独立元数据。智联收起时的模块入口、样式、虚构候选、异步等待和事件处理仍在本地重建。完整差异见生成的 `manifest.json`。
- 智联 iView 学历下拉的现场实验确认：DOM `.click()` 单独执行不提交选择，`mousedown` 后提交。离线驱动现在在同一事件阶段提交，回归含“只有 click 不得提交”的反例。
- Moka 旧样本曾把出生控件后续转换模拟为日精度。2026-09-20 原站再次核对确认该控件提交年月并附带年龄；离线交互已按此修正，仍不能替代正式 MCP 在原站的填写验收。
- 飞书补采工作、项目、作品、竞赛、证书、语言能力、自我评价、社交账号八个原先收起的模块。作品附件的上传操作不纳入自动填写夹具，作品链接与描述保留。
- 智联补采教育、工作／实习、项目、培训、语言、技能、证书、学生干部、个人优势九个新增表单，以及求职状态、求职意向编辑表单；个人信息补入政治面貌。
- 智联教育初始只有学历与海外学习标记，选择本科后出现学校、统招、学位、专业、在校时间。仅这两个状态实际采集；其他学历分支、干部类别依赖候选、学校／专业远程搜索结果均未完整采集，不能据此宣称已复刻。
- 智联地区、行业使用 S 级联对话框，职位使用独立的 iView Modal / job-type 列表；三份初始弹层分别采集，后续虚构层级选择在本地重建。求职意向原站存在多选，此处仅重放单条路径，未覆盖多选数量限制与确认行为。
- Moka 这份表单的“所在地”“期望城市”是普通输入框，不把它们伪造成级联。地区弹窗测试来自智联实际打开的结构。

## 使用

```sh
npm run lab:ats
```

打开 `http://127.0.0.1:4175/`。Moka、飞书、智联三页分别为 `/moka.html`、`/feishu.html`、`/zhaopin.html`。服务器只绑定回环地址；`ATS_OFFLINE_PORT` 可以指定其他本地端口。

字段初始为空，所有候选都是公共枚举或虚构测试值。“保存测试草稿”只更新内存计数，不连接原站。新模块默认收起，可点击添加或编辑，重复新增会创建独立记录，“取消本条”清理该条字段与受控值。智联教育字段按学历展开；年月范围支持“至今”禁用结束时间。

```sh
npm run test:ats
```

测试启动随机端口服务和隔离临时 Chrome，通过实际构建的 Resume Browser MCP 执行。记录两种不同结果：

1. **夹具功能验证**：本地选择、日期、地区、重复记录能更新独立受控值；没有外网资源和真实提交。
2. **产品兼容基线**：`form_observe` 对字段的识别情况，以及已支持的 Moka 语义填写。飞书/智联的夹具交互通过不计成高层工具已兼容。

测试里的 DOM 点击只在这些本地合成页面执行，用于确认夹具行为；不能用它替代产品语义工具的兼容验收。`fixtureOracle` 仅由测试读取，生产执行器不读取它。

扩展回归检查全部 19 个新增／编辑模块、教育字段联动、日期至今、行业与职位逐级选择、单选、竞赛和语言选择、重复记录值隔离、取消清理，以及原站重复 ID 保留。夹具测试通过仍不代表这些行为已能由生产语义工具完成。

`fidelity.mjs` 直接读取独立的原站 v2 捕获文件，对照生成页面的字段根节点、控件属性、控件父层级和记录祖先链，不以生成器自己的输出作为唯一预期。结果的 `initial_fidelity` / `expanded_fidelity` 记录检查数量和差异。已选状态、输入值和被明确移除的浮层／已选标签不参与静态一致性比较；检查通过只证明所列结构与属性一致，不覆盖像素、原站框架内部状态、接口协议或全部交互。

夹具运行器的定位标记统一使用 `data-fixture-*`，不计入源站属性对照；生产语义执行器不读取这些标记。对照也检查额外出现的语义属性，防止离线代码擅自增加 `aria-label`、`name` 等识别线索。

后续修复应先用这些页面复现，再回真实招聘页面验证。新增站点或变体时记录实际观察状态，避免把推测的行为写成已经捕获的行为。
