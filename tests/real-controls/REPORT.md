# 0.17.0 复杂控件验证记录

日期：2026-09-19。环境：macOS、Node.js 24.15.0、Chrome 153.0.8010.52、固定 chrome-devtools-mcp 1.9.0。所有自动化场景使用 localhost 虚构资料及隔离临时 Chrome Profile。

## 实现范围

新增 `browser/controls` 的公开 DOM 读取、控件执行、严格验证和有界事务；继续使用既有 Supervisor、互斥锁与六个语义表单工具。没有读取 React/Vue 私有状态、重放网站写 API 或新增站点专用规则。

日期支持日期/年月、明确格式输入、只读日历和确认。完成后等待弹层关闭，并通过不改变选择的面板导航复核状态。级联逐层验证父子路径，支持慢加载、悬停、父级选择及叶子回显。多选区分增补和显式替换；范围区分起止端点与至今。控件不能证明目标已完成时不返回 `verified_ui`。

## 执行器耗时

固定 Ant5 D02（只读日期）、C02（三级地址）、V01（第 175 个虚拟候选），每场景 20 份新文档。浏览器预先启动；排除导航、启动、模型思考与测试 oracle 查询。

“重复同值”紧接成功后的首次调用，使用新的 operation ID，因此不是传输结果缓存命中。首次失败时跳过重复同值，单列 skipped。P50/P95 包含全部实际执行样本，不剔除失败。响应字节是完整 MCP 结果 JSON，和早期仅计算文本内容的记录不能混算。

## 真实验收及限制

交通银行前批解析修复只验证过已填状态、栏目、保存按钮作用域和候选。本轮收尾时专属浏览器仅剩新标签页，未进行 0.17.0 真实填写或保存。另两类招聘系统按用户安排稍后提供。

支持承诺限定于已测样本：Element 长列表使用普通 ElSelect，未测 ElSelectV2 或旧 Element UI 2。未知格式/精度、时间/周/季度/仅年份、原生非单位 date step 和无法证明完整集合的折叠多选会停止。未全面覆盖就地换单列级联、逐层中断全矩阵、全部日期范围联动变体。

`verified_ui` 只证明界面值；普通保存返回派发事实和 `persistence=unknown`。取消不回滚。照片上传、声明和最终提交仍由用户完成。
