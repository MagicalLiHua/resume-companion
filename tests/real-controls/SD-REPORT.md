# SD 风格控件诊断与开发回归

> 2026-09-20 更新：本文保留第一轮 SD 单选修复记录。0.18.0 已新增分拆年月组和多列 SD 路径的本地实现与回归，当前范围见[选择控件增量验证](SELECTION-REPORT.md)；真实招聘网站完整验收仍待进行。

日期：2026-09-19。基于已安装的 0.17.0 发现的问题；本文件描述尚未发布、尚未安装到当前专用浏览器的源码修复。

## 真实证据

在 Moka 申请表中，原观察返回 61 个字段、0 个栏目。大量选择框被标成普通 text，名称为“请选择”“年”“月”或当前显示值。民族菜单实际打开后，原工具仍报告 overlay=closed。

公开 DOM 显示：输入框在 `sd-Input-container-*` / `sd-Select-container-*` 的 label 包装中，选中值在 `sd-Input-display-value-*`，下拉位于同一 `sd-Dropdown-container-*` 的兄弟子树内，候选为没有 option 角色的 `sd-Select-common-item-*` div。字段标题和栏目标题位于外层。星号节点、添加按钮及显示值不能混入字段/栏目名称。

这是组件结构识别缺口。0.17.0 的 Ant/Element 280 次测试不能代表这一类控件已经兼容；未从类名推断确切组件库版本。

## 修复与边界

- 新增 SD 单选状态与候选读取，复用既有有界执行和严格值验证。弹层按同一组件容器归属，不能选另一个已打开下拉里的同名值。
- 按组件类名前缀及公开结构识别，忽略构建哈希；不使用 Moka 域名、具体招聘公司、字段值或网站接口作为匹配条件。
- 用局部标题/控件关系恢复标签和栏目；跳过作为控件包装的 label，避免将显示值当作名字。区号和手机号码使用不同目标。
- 对明确的四段年月结构生成开始年、开始月、结束年、结束月。此项只让子选择器可以准确寻址，不等于 `form_set_date(range=...)` 已支持这一组合。
- 籍贯地址弹层、整组日期提交、出生日期、SD 多选及远程搜索变体尚未完成验收。不宣称 Moka 全站适配完成。

新解析器在当前真实页面只读对照中恢复了 10 个栏目，并识别性别、婚姻状况、国家/地区、民族、学历、学校/专业及语言能力等选择字段；性别显示值被识别为已填，手机号与区号不再歧义。这里验证的是识别，不是这些字段逐项填写成功。

真实页面仅展开/关闭民族菜单、按 Escape 收起，并进行只读结构检查；未选择候选、保存草稿、上传或提交。原页面与现有服务没有被升级或重载。诊断客户端曾因遗漏 TMPDIR 连到错误端点，修正环境后恢复连接；额外空服务已关闭，未删除浏览器锁。
