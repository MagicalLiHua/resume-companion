# 简历随行 0.5.0

开源、本地优先的简历维护与网申填写工具。浏览器扩展可靠地读取和填写 DOM；Codex 插件负责理解字段、汇总多个标签页并生成待确认计划。资料不需要上传业务后端，填写工具不提供提交申请能力。

## 安装与使用

从源码安装时先运行 `npm ci && npm run build`，然后在 Chrome 的 `chrome://extensions` 开启开发者模式并加载生成的 `dist` 文件夹。发布包用户可解压 `resume-companion-0.5.0.zip`，加载其中的 `extension` 文件夹。

1. 在“我的简历”新建、复制或维护命名版本；补充资料随各版本保存。
2. 使用“从 AI 导入”的提示词获得固定模板 Markdown，核对差异后保存。
3. 在“模型设置”填写接口格式、提供商地址、模型名称和自己的 API Key。支持 Anthropic / OpenAI 兼容格式，首轮真实验证使用 DeepSeek。
4. 在招聘页面点击右下角悬浮球，选择本次简历版本，核对字段后“确认填写 ✓”。工具栏侧边栏也可使用。
5. “投递记录与统计”自动留下检测到的提交信息，也可手动补记。记录直接进入统计，无待确认/已确认流程。

完整操作见[安装与体验](docs/安装与体验.md)，当前交付见[交付说明](docs/当前交付与启动.md)。需要由 Codex 枚举和批量填写多个标签页时，参见[Codex 批量网申能力](docs/Codex网申能力最小验证.md)。

## Codex 批量网申

项目内的 `plugins/resume-companion` 是自包含 Codex 插件，本机 MCP 服务通过 `127.0.0.1:43117` 与 Chrome 扩展交换结构化数据。启用设置页的“Codex 本地桥接”后，Codex 可以列出普通网页标签页、扫描用户选中的最多 20 页、合并展示填写预览，并在用户明确确认后批量填写、回读或撤销。

扩展和 Codex 插件都没有提交、下一步、上传、验证码、密码或接受声明的工具。标签页导航、表单结构变化、简历版本变化及未确认的已有值覆盖都会使旧计划失效。

## 本地数据与填写边界

资料、草稿、所有简历版本和投递记录保存在当前浏览器，完整 JSON 备份可迁移。Key 在设置页输入，默认仅保留在会话，可选择本机记住；不进入分享包或资料备份。

模型只在主动连接测试或核对发送内容后调用，字段说明会发送到所选提供商；实际资料值在本地解析后填写。不会自动提交申请。复杂控件、跨域 iframe 和未适配的网站仍可能需要手工操作。

自动悬浮入口需要普通 HTTP/HTTPS 网页权限；已按用户要求启用，可在“备份与恢复”关闭显示。升级前导出备份，在固定加载目录替换文件后点击“重新加载”，保持开发者模式开启。

## 验证

类型检查、构建、69 项单元测试、51 项浏览器测试通过。合成表单覆盖 20 类、200 个标注字段；包括多版本、悬浮窗口、草稿与恢复、Key 隔离、模型故障处理、投递记录、0.3.1/0.3.2 升级和旧 JSON 回退。另有 MCP 契约自测和真实 Chrome 三标签页纵向测试，覆盖枚举、批量扫描、填写、回读、条件撤销、活动页不切换和零提交。

已使用真实 DeepSeek Anthropic API 完成配置页连接、字段建议、确认填写和回读。真实招聘网站按用户安排稍后试用，Edge / Windows 未实际复测。完整证据见[实现与验收](docs/纯插件版实现与验收.md)。

## 开发

```sh
npm ci
npm run check
npm run package
npm run lab
cd plugins/resume-companion && npm test && npm run test:live
```

使用 Node 24。浏览器测试可通过 `RESUME_TEST_BROWSER` 指定 Chrome for Testing 路径，macOS 会优先复用已安装的测试浏览器。`npm run lab` 提供本地合成表单，不需要业务后端。

源码入口：`extension/src/options`（资料与模型设置）、`sidepanel`（侧栏/悬浮窗口）、`journal`（投递记录）、`content`（网页扫描、悬浮入口、填写和提交观察）、`domain`（资料、版本、解析、匹配和备份）、`background`（可信存储与消息）、`network`（模型协议）。

历史网页、后端和相应验收材料保留在 `web`、`backend` 和 `docs/历史版本`，不作为 0.5.0 运行依赖。旧服务器状态见[历史交付说明](docs/历史版本/当前交付与启动-0.3.2.md)。本项目使用 [MIT License](LICENSE)。
